# 用户导入模板说明

## 1. 适用范围

该模板仅用于导入 `builtin` 内置账号。

不适用于：

- LDAP 用户
- OIDC / IDaaS 用户
- 外部用户目录同步

## 2. 模板结构

导入文件必须为 `xlsx` 格式，且包含名为 `users` 的工作表。

表头固定如下：

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| `username` | 是 | 用户名，必须唯一 |
| `initial_password` | 是 | 初始明文密码，由服务端按当前 `passwordSalt` 计算哈希 |
| `roles` | 否 | 多个角色用英文逗号分隔，例如 `admin,user` |

## 3. 示例

```text
username,initial_password,roles
admin.local,Strong@123456,admin
zhangsan,Temp@123456,user
lisi,Temp@123456,"user,ops"
```

## 4. 导入模式

配置管理 UI 当前支持两种导入模式：

- `append`
  追加导入。若模板中的用户名已存在，则整次导入失败。
- `overwrite`
  按用户名覆盖。若用户名已存在，则更新该用户密码，并用模板中的角色覆盖该用户原有角色关系。

## 5. 校验规则

导入时至少会校验以下内容：

- 工作表名称必须为 `users`
- `username` 列不能为空
- `initial_password` 列不能为空
- 同一文件内用户名不能重复
- `roles` 会自动去空格、去重

## 6. 密码处理

导入接口不会保存或回显明文密码。

处理规则如下：

1. 读取模板中的 `initial_password`
2. 按当前配置中的 `passwordSalt` 计算 `MD5(passwordSalt + 明文密码)`
3. 将结果写入 `auth.builtinUsers`

如果 `passwordSalt` 为空，则退化为 `MD5(明文密码)`。

## 7. 操作入口

当前入口位于配置管理 UI：

1. 打开“认证与用户”
2. 在“内置用户”卡片点击“下载模板”
3. 按模板填写后点击“导入用户”
4. 选择导入模式并上传 `xlsx`

导入成功后，系统会直接写入 `config.yaml` 并热重载，无需重启。
